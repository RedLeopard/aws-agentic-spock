Project Spock | Agentic CX Designer

The project

A portfolio you can call.

I built Spock as a conversational guide to my portfolio. It asks what brings someone in, then uses that answer to explore a business need, discuss a hiring priority, or walk through a project.

01 / Solution architecture

One welcome.
Three conversation paths.

Agentic CX Designer decides which journey to start and gives Spock read-only access to project facts it can use in an answer.

  1. 01 / Channel

    Amazon Connect

    Provides the phone entry point. Designer chat is used to exercise the journeys before a wider rollout.

  2. 02 / Conversation design

    Agentic CX Designer

    Starts the welcome flow, routes by intent, and runs generative journeys for potential clients, recruiters, and demo visitors.

  3. 03 / Portfolio evidence

    Read-only data requests

    Supply documented decisions and project links so Spock can give a relevant example with the right scope.

Separate delivery path. The recruiter journey can call an authenticated Lambda webhook for requested links. The stack uses AWS Secrets Manager for the webhook key and DynamoDB to guard against duplicate attempts.
